  Each time this unit makes an ingress move (20.04), if every model in this unit has this ability, it can be set up
  anywhere on the battlefield that is more than 8" horizontally from all enemy units, even if that is within your
  opponent’s deployment zone.

  Feel No Pain 5+:
  This ability always takes the form Feel No Pain X+. Each time a model with this ability would lose a wound, roll
  one D6: on an X+, that wound is not lost.

  Get Stuck In:
  Friendly ORKS units' melee attacks have [SUSTAINED HITS 1].

  Leader:

  friendly bodyguard unit that unit can lead. That unit will then lead that bodyguard unit for the battle and form an
  attached unit with it. Unless otherwise stated, each bodyguard unit can only have one leader unit and one
  support unit attached to it.

  Support:

  friendly bodyguard unit that unit can lead. That unit will then lead that bodyguard unit for the battle and form
  an attached unit with it.
