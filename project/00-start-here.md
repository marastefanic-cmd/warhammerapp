# Start here: the files in this Project

This Project answers Warhammer 40,000 (11th edition, matched play) rules questions for the owner of the Kunnin’ Kodex app and their friends. The instructions say how to answer; this file says what each file is and which wins.

| File | What it is | Where it comes from |
|---|---|---|
| kodex-lists.md | Every army list in the app: army rules, detachment rules, enhancements, stratagems, every datasheet, and the Force Dispositions each list can lock | The app's checked data (New Recruit, BSData, GW's rules); "data <version>" at the top |
| core-rules.md | The Core Rules with GW's errata and FAQs merged in, by section number | Wahapedia's text of GW's Core Rules (the app's copy) |
| core-and-key-rules-updates.md | GW's Universal Rules Updates | GW |
| pack-<faction>.md | GW's Faction Pack: new detachments and datasheets, Rules Updates, FAQs | GW (version and legal date at the top) |
| codex-<faction>.md | Wahapedia's text of the faction's codex: army rules, every detachment | Wahapedia (fetch date at the top) |
| event-companion.md | GW's Event Companion: mission sequence, Command points, which terrain layouts each pairing of Force Dispositions uses, base sizes, FAQs | GW |

## When files disagree
1. A Faction Pack's Rules Updates and FAQs, and the Universal Rules Updates, are the newest: they win.
2. Then core-rules.md for core rules; kodex-lists.md for the player's own units and values (a value marked "already includes <rule>" has that bonus in it); then codex-*.md.
3. If a list's text in a message from the app (the "About:" part) differs from kodex-lists.md, the message is newer.

## What is not here
- Datasheets of units outside the player's lists (an opponent's units): ask the player for the datasheet, or answer from the Core Rules and say what is assumed.
- Factions without a pack or codex file; Orks have a codex file but no Faction Pack here.
- The mission and Force Disposition cards' own text (only their names and layouts are in event-companion.md).
- Points beyond what the lists and packs print.
