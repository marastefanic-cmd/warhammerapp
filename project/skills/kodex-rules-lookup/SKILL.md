# Finding the current rule

## Where each kind of rule lives
| Need | Look here first | Then |
|---|---|---|
| Core rule (movement, shooting, charge, fight, keywords like [LETHAL HITS], terrain, transports) | core-rules.md in this Project (section numbers) | Core Rules updates / FAQ on GW's downloads page newer than core-rules.md's date |
| A faction's army rule, detachment rule, enhancements, stratagems | Wahapedia faction page (table below) | that faction's Faction Pack on GW's downloads page (Rules Updates, FAQs, new detachments win) |
| A datasheet (stats, weapons, abilities, keywords, wargear, leader rules) | Wahapedia datasheet page | the Faction Pack's Rules Updates for that datasheet |
| Missions, Force Dispositions, Command points, base sizes, event FAQs | GW's Event Companion (downloads page) | detachment-dispositions.md for which dispositions a detachment allows |
| What a player's own unit has in their list | the KODEX block in the message, if there is one | the datasheet, if the question needs the original |

GW downloads page: https://www.warhammer-community.com/en-gb/downloads/warhammer-40000/ (each document shows its date; the PDFs are on assets.warhammer-community.com). Each Faction Pack states "Version x.y, legal for matched play from <date>" on its first page: the highest version is current.

Wahapedia, 11th edition only (`/wh40k11ed/`): core rules https://wahapedia.ru/wh40k11ed/the-rules/core-rules/ · faction page https://wahapedia.ru/wh40k11ed/factions/<slug>/ · datasheet https://wahapedia.ru/wh40k11ed/factions/<slug>/<Datasheet-Name> (words capitalised, joined by hyphens, e.g. `orks/Big-Mek-In-Mega-Armour`; if that 404s, open the faction page and follow its link).

Faction slugs: adepta-sororitas · adeptus-custodes · adeptus-mechanicus · aeldari · astra-militarum · chaos-daemons · chaos-knights · chaos-space-marines · death-guard · drukhari · emperor-s-children · genestealer-cults · grey-knights · imperial-agents · imperial-knights · leagues-of-votann · necrons · orks · space-marines (Blood Angels, Dark Angels, Space Wolves, Black Templars and Deathwatch are on the space-marines page and its datasheets) · t-au-empire · thousand-sons · tyranids · world-eaters.

## Steps
1. Name the rules the answer depends on (the ability, the stratagem, the core rules section, and any keyword they use).
2. For each, read its current text from the table above. Prefer one page fetch per faction; take what you need and keep it for the rest of the chat.
3. Check the faction's Faction Pack for a Rules Update or FAQ that names that rule (it wins). If the pack is newer than what Wahapedia shows, use the pack and say so.
4. Make sure every page is 11th edition (`/wh40k11ed/` in the address; GW documents dated from 2026 on). If a page is another edition or game, discard it.
5. Answer as the Project's instructions say, quoting the text with its source and link.

## "Is anything out of date?" / "What changed?"
Open GW's downloads page. For core-rules.md and each Faction Pack the player plays or asks about, compare GW's newest version and date with the file's first lines or what was used in this chat. Report each document: current / newer version available (with its date and link). For a newer Faction Pack, summarise its Rules Updates and FAQs in a few lines. If core-rules.md or detachment-dispositions.md is out of date, tell the player to get a fresh copy from the app's GitHub site (project/ folder) and replace the file in the Project.
